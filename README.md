# Azzurro Café – Smart PWA Application

Welcome to **Azzurro Café**, a modern Progressive Web App (PWA) designed for a stylish café experience.  
This app allows customers to browse the menu, add items to the cart, and place orders directly via WhatsApp.

---

## ✅ Features
- **Responsive Design** – Works on desktop and mobile.
- **Progressive Web App (PWA)** – Installable and offline support.
- **Menu with Search** – Find items easily.
- **Cart & Order System** – Add items and place orders via WhatsApp.
- **Social Links** – Instagram integration.
- **Custom Branding** – Includes café logo and hero image.
